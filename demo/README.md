# demo/

웹앱 데모에 쓰는 파일입니다.

| 파일 | 설명 |
|---|---|
| `s1.mp4` ~ `s3.mp4` | 데모 ①~③의 **AI 생성 영상** (10초, 1280×720, 24fps, 오디오 제거). 웹앱에서 **영상 실처리**를 고르면 YOLO가 이 영상을 실제로 탐지합니다 |
| `s1.json`, `s2.json` | 영상 실처리 때 적용되는 구역 (0~1 정규화 다각형). `s1` = 영상의 초록 휴게구역, `s2` = 작업자·굴착기 작업 반경 |
| `source/` | (git 제외) 오디오가 포함된 원본과, 데모에서 뺀 영상(역광 `s4`, 샘플 실영상 `street_bus`) |

- 영상 파일이 없으면 해당 데모는 **시뮬레이션**(장면을 그려 넣고 탐지값을 시나리오로 정함)으로만 동작합니다.
- 영상 속 CCTV 날짜 표시와 우측 하단의 ✦ 표시는 생성 도구가 넣은 것으로, 실제 현장 기록이 아닙니다. 웹앱은 이 영상에 "AI 생성 영상" 배지를 표시합니다.
- 영상을 바꾸려면 같은 이름으로 교체하세요. 구역이 필요하면 같은 이름의 `.json` 을 두세요. 웹앱의 구역 그리기 → **JSON 복사**로 만들 수 있습니다.

```json
{"danger": [[[0.08, 0.48], [0.78, 0.48], [0.78, 0.99], [0.08, 0.99]]], "rest": []}
```

프롬프트와 영상 조건은 [docs/DEMO_VIDEO_PROMPTS.md](../docs/DEMO_VIDEO_PROMPTS.md) 를 보세요. AI 영상은 생성 도구의 이용 약관(상업적 이용·재배포)을 확인한 뒤 저장소에 올리세요.
