# demo/

웹앱 데모에 쓰는 파일입니다.

| 파일 | 설명 |
|---|---|
| `street_bus.mp4` | 샘플 실영상 (데모 ⑤, YOLO 실처리) |
| `s1.mp4` ~ `s4.mp4` | **선택.** 데모 ①~④의 실제 영상. 있으면 웹앱에서 "영상 실처리"를 고를 수 있고, 없으면 시뮬레이션으로 동작 |
| `s1.json` ~ `s4.json` | **선택.** 영상 실처리 때 적용할 구역. 0~1로 정규화한 다각형 |

구역 JSON 형식 (웹앱의 구역 그리기 → **JSON 복사**로 만들 수 있습니다):

```json
{"danger": [[[0.2, 0.5], [0.75, 0.5], [0.75, 0.98], [0.2, 0.98]]], "rest": []}
```

영상 제작용 프롬프트와 조건은 [docs/DEMO_VIDEO_PROMPTS.md](../docs/DEMO_VIDEO_PROMPTS.md) 를 보세요.
